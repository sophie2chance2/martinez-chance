# Image upload guide

- `hero.jpg`: one strong horizontal engagement image
- `story-01.jpg` through `story-04.jpg`: childhood, early relationship, candid, engagement
- `venue.jpg`: The Lane or a San Diego architectural detail
- `party/`: one portrait per wedding-party member
- `outfits/`: colorful formalwear inspiration
- `things-to-do/`: San Diego recommendations

The current website uses designed placeholders until these files are added.
